# Flux Japanese Girl LoRA 学習手順

## Podを起動したら最初にやること（3ステップ）

### Step 1: HFトークンを書く
```bash
echo "hf_xxxxxxxx" > /tmp/hf_token.txt
```

### Step 2: セットアップスクリプトをアップロード
（Claudeが自動でやります）

### Step 3: スクリプトを実行するだけ
```bash
python3 /workspace/setup_girl_lora.py
```

---

## スクリプトが自動でやること

| ステップ | 内容 |
|---------|------|
| 1 | HFトークン確認 |
| 2 | FLUX.1-devモデル確認（/workspace/models/flux_dev/） |
| 3 | データセット確認（26枚 + キャプション） |
| 4 | Pythonパッケージ確認・インストール |
| 5 | ai-toolkitを /root/ にインストール（ローカルストレージ） |
| 6 | save_training_config quotaエラー対策パッチ |
| 7 | 学習設定ファイル生成（Python yamlで文字化けなし） |
| 8 | 出力ディレクトリ作成・書き込みテスト |
| 9 | ComfyUI停止（VRAM確保） |
| 10 | バックグラウンドで学習開始 |

---

## 学習中の監視

```bash
# リアルタイムログ
tail -f /tmp/lora_train.log

# ステップ進捗のみ
grep -E 'loss|step' /tmp/lora_train.log | tail -20

# 完了確認
ls /workspace/output/flux_japanese_girl_lora/flux_japanese_girl_v1/
```

---

## 学習設定

| 項目 | 設定値 |
|------|-------|
| モデル | FLUX.1-dev（量子化あり） |
| トリガーワード | `ohwx woman` |
| ステップ数 | 2000 |
| LoRAランク | 16 |
| 学習率 | 1e-4 |
| バッチサイズ | 1 |
| サンプル生成 | 500stepごと |

---

## エラーが出た場合

### CUDA out of memory
```bash
# ComfyUIを強制停止
pkill -9 -f comfy
# 再実行
python3 /workspace/setup_girl_lora.py
```

### 学習が止まっている
```bash
# ログ確認
tail -50 /tmp/lora_train.log
# プロセス確認
pgrep -f run.py
```

### 完了後 - LoRAをNetworkVolumeに保存確認
```bash
ls -la /workspace/output/flux_japanese_girl_lora/flux_japanese_girl_v1/*.safetensors
```
