## 動画スクリプト生成

複数のクリップを繋いだ1本のショート動画用に、テロップとナレーション原稿を作成し、Irodori-TTS VoiceDesign で音声ファイルを生成する。

### 前提知識

- `作業中動画/` 内の `.mp4` ファイルは**すべて1本の動画を構成するクリップ**
- **テロップ**: クリップごとに1枚ずつ表示。クリップ数＝テロップ枚数
  - 1枚目 → フック／最後 → 行動喚起／それ以外 → 本題（複数可）
- **ナレーション**: 全クリップ合計時間に収まる1本の連続した原稿
- **音声合成**: Irodori-TTS VoiceDesign（GPU不要・テキストで声質指定・48kHz高音質）

### Step 1: 動画ファイルと合計尺を確認する

!`ls "/Users/keeee/Desktop/Dev/OssMovieAIz/作業中動画/"*.mp4 2>/dev/null`

ファイルが0本なら「作業中動画フォルダに動画ファイルが見つかりませんでした」と伝えて終了する。

合計尺を計測する:

!`python3 -c "
import subprocess, glob
files = sorted(glob.glob('/Users/keeee/Desktop/Dev/OssMovieAIz/作業中動画/*.mp4'))
total = 0
for f in files:
    r = subprocess.run(['ffprobe','-v','quiet','-show_entries','format=duration','-of','csv=p=0',f], capture_output=True, text=True)
    total += float(r.stdout.strip() or 0)
print(f'合計: {total:.1f}秒')
"`

合計尺（秒）を記憶する。

---

### Step 2: ナレーションのペースと話者を選ぶ

ユーザーに以下を**まとめて**聞く:

**① ナレーションのペースを選んでください:**
1. ゆっくり（落ち着いた・高級感）
2. 普通（自然な話し言葉）
3. 早口（テンポよく・エネルギッシュ）

**② 声の説明テキスト（キャプション）を指定してください:**

Irodori-TTS VoiceDesignで声質・感情をテキストで自由に指定できます。

> 例: 「落ち着いた女性の声で、やわらかく自然に話してほしい」
> 例: 「やや低めの男性の声で、信頼感のあるトーンで丁寧に」
> 例: 「明るく元気な若い女性の声で、楽しそうに話してほしい」
> 例: 「20代後半の女性の声で、友達に話すようなナチュラルなトーン」

ユーザーの回答をもとに **ナレーション上限文字数** を決定する:
- ゆっくり → **ナレーション対象秒数** × 3
- 普通     → **ナレーション対象秒数** × 5
- 早口     → **ナレーション対象秒数** × 7

⚠️ **「ナレーション対象秒数」は動画合計秒数ではない。** タイトルカード・エンドカード・無音演出など、ナレーションを入れないシーンの尺を除いた秒数を使う。Step 4 でナレーション範囲を確定してから最終的な上限を計算する。

---

### Step 3: 全クリップのフレームを抽出・分析する

各 `.mp4` ファイルに対して順番にBashで実行する（`VIDEO_PATH` を実際のパスに置き換え）:

```
mkdir -p /tmp/video-script-frames && ffmpeg -i "VIDEO_PATH" -vf "fps=1/5,scale=640:-1" /tmp/video-script-frames/frame-%03d.jpg -y 2>/dev/null && ls /tmp/video-script-frames/
```

抽出したフレームを Read ツールで読み込み、クリップの内容（商品・人物・シーン・雰囲気）を把握する。全クリップ分繰り返す。

---

### Step 4: ナレーション範囲を確定し、スクリプトを生成する

#### 4-1. ナレーション範囲を決める

全シーンの中から**ナレーションを入れるシーン**と**入れないシーン**を分類する。

**ナレーションを入れないシーンの典型例:**
- タイトルカード（黒バック+店名など）
- エンドカード（CTA・連絡先）
- 無音で映像に集中させたいシーン（インパクト演出）

**テーブルで整理する:**
```
| シーン | 尺 | ナレーション | 理由 |
|-------|-----|------------|------|
| Scene 1（タイトル） | 3秒 | なし | テキスト演出のみ |
| Scene 2（導入） | 5秒 | あり | |
| Scene 3（本題1） | 5秒 | あり | |
| ... | ... | ... | |
| Scene N（エンドカード） | 7秒 | なし | CTA表示 |
| **ナレーション対象合計** | **XX秒** | | |
```

**ナレーション対象秒数**を確定し、Step 2 のペースに基づいて**最終的な上限文字数**を計算する:
- ゆっくり → ナレーション対象秒数 × 3
- 普通 → ナレーション対象秒数 × 5
- 早口 → ナレーション対象秒数 × 7

**ナレーション開始タイミング（Remotion `from` フレーム）も決める:**
- ナレーション対象の最初のシーンの開始フレーム = ナレーション開始フレーム
- 例: Scene 1（3秒=90フレーム@30fps）がタイトルで、Scene 2からナレーション開始 → `from={90}`
- 例: Scene 1からナレーション開始 → `from={0}`

#### 4-2. スクリプトを生成・保存する

分析結果をもとにスクリプトを生成し、Bash で `/Users/keeee/Desktop/Dev/OssMovieAIz/作業中動画/テロップとナレーション.md` に書き出す。

**出力フォーマット**:

```
# テロップ・ナレーション原稿

## テロップ（クリップごと）

| クリップ | 役割 | テロップ（15文字以内） |
|---------|------|----------------------|
| scene1_xxx | フック | （驚き・問いかけ） |
| scene2_xxx | 本題 | （根拠・解説の要点） |
| scene3_xxx | 行動喚起 | （保存・フォロー等） |

## ナレーション（全体通し・〇〇文字／上限〇〇文字）

（ここにナレーション本文）

## ナレーション設計

- ナレーション対象シーン: Scene X 〜 Scene Y
- ナレーション対象秒数: XX秒（動画合計: YY秒）
- ナレーション開始フレーム（Remotion `from`）: ZZ（= Scene Xの開始位置 @30fps）
- ナレーション終了目安: エンドカード開始の約1秒前

## 話者情報
- エンジン: Irodori-TTS VoiceDesign
- キャプション: [声の説明テキスト]
- ペース: [ゆっくり/普通/早口]
```

**ナレーション作成の制約**:
- 文字数が **上限を超えないこと**（上限 = ナレーション対象秒数 × ペース係数）
- **上限の85〜100%を使い切る。** 短すぎると映像に対してスカスカになる
- フックで興味を引き → 本題で価値を伝え → 行動喚起で締める流れ
- です/ます調、話し言葉で自然に
- 生成後、必ず文字数をカウントして範囲内か確認する

保存後、以下を表示してユーザーに確認する:

```
✅ テロップとナレーション.md を保存しました

【ナレーション確認】
---
（ナレーション本文をここに表示）
---
文字数: 〇〇文字 / 上限: 〇〇文字（目標: 上限の85〜100%）
目安の音声時間: 〇〇秒 / ナレーション対象: 〇〇秒（動画全体: 〇〇秒）
開始: Scene X から（Remotion from=ZZ）

修正したい場合は修正文を教えてください。OKならStep 5に進みます。
```

ユーザーが修正を伝えた場合:
1. 修正後のナレーションで `テロップとナレーション.md` を更新する
2. 再度確認を表示する
3. OKが出たら Step 5 に進む

### Step 5: 音声を生成し、ナレーション対象範囲に収まるか確認する

Step 2 で選んだ話者IDと Step 4 のナレーション本文で音声を生成する。
生成後に実際の長さを測り、**ナレーション対象秒数**と比較する（動画全体の尺ではない）。

#### 5-1. 音声を生成する

Step 2 で選んだキャプションと Step 4 のナレーション本文でBashで実行する。`NARRATION_TEXT` と `CAPTION` を実際の値に置き換え:

```
python3 /Users/keeee/Desktop/Dev/OssMovieAIz/scripts/generate_tts_irodori.py \
  --text "NARRATION_TEXT" \
  --caption "CAPTION" \
  --output "/Users/keeee/Desktop/Dev/OssMovieAIz/public/narration.wav"
```

⚠️ **Irodori-TTSの尺ブレに注意:** Irodori-TTSはseedが毎回ランダムなため、同じ文字数でも出力尺が大きくブレる（例: 70文字で14秒→25秒）。文字数×ペース係数の推定は目安にしかならない。対策:
- 良い尺が出たらseedをログから控えておく（`[seed] used_seed: XXXX` で表示される）
- 文字数を調整して再生成 → 尺を計測 → 目標に近づくまで繰り返す
- 良いseedが見つかったら `--seed SEED` で固定して文字数調整のみで微調整する

#### 5-2. 音声の長さを計測する

```
ffprobe -v quiet -show_entries format=duration -of csv=p=0 "/Users/keeee/Desktop/Dev/OssMovieAIz/public/narration.wav"
```

#### 5-3. ナレーション対象秒数と比較する

**比較対象は「ナレーション対象秒数」（Step 4-1 で確定した値）であり、動画全体の合計秒数ではない。**

生成後、以下を報告する:

```
narration.wav を生成しました
音声: XX秒 / ナレーション対象: YY秒（動画全体: ZZ秒）
開始フレーム: from={N}（Scene Xから）
ナレーション終了位置: 動画の XX秒地点（エンドカード開始の約Y秒前）
```

- **音声秒数がナレーション対象秒数の±2秒以内** → OK
- **音声秒数 > ナレーション対象秒数** → 自動で縮めて再生成する（最大3回）:
  1. 新目標文字数 = `floor(現在の文字数 × 対象秒数 / 音声秒数 × 0.9)`
  2. ナレーション本文を縮める（流れ・です/ます調を維持しつつ削る）
  3. `テロップとナレーション.md` を更新 → 5-1 を再実行
- **音声秒数がナレーション対象秒数より5秒以上短い** → **自動で伸ばして再生成する（最大2回）**:
  1. 新目標文字数 = `floor(現在の文字数 × 対象秒数 / 音声秒数 × 0.95)`
  2. ナレーション本文を自然に伸ばす（描写を追加・文を丁寧にする等）
  3. `テロップとナレーション.md` を更新 → 5-1 を再実行
- **音声秒数がナレーション対象秒数より3〜5秒短い** → ユーザーに確認:
  ```
  ナレーションが対象範囲より〇〇秒短いです。
  ① このままでよい（後半に余韻の間が入る）
  ② ナレーションを伸ばす
  ```
- 3回試しても収まらない場合は現状を報告してユーザーに確認する

### Step 6: BGMを設計・生成する

ナレーション完成後、動画全体のBGMを設計して生成する。

#### 6-1. BGM戦略を尺に応じて決める

| 動画尺 | 生成戦略 | 備考 |
|-------|---------|------|
| **〜30秒** | 1発生成 | `--duration`をそのまま指定。ACE-Stepが直接出力 |
| **31〜60秒** | 自動2分割 | スクリプトが自動で分割+クロスフェード |
| **61秒〜** | 自動2分割 | 同上。ただし長すぎると品質が落ちるため90秒が実用上限 |

#### 6-2. BGMの雰囲気をユーザーと決める

以下を提案してユーザーに確認する:

```
BGMの方向性:
- ジャンル: [acoustic / cinematic orchestral / lo-fi / jazz / electronic 等]
- 楽器: [guitar / piano / strings / synth 等]
- 雰囲気: [warm / energetic / calm / dramatic 等]
- テンポ感: [slow / moderate / upbeat]
```

**30秒超の場合は2パート構成を提案する:**
```
Part 1（前半）: [穏やかなイントロ — 例: soft piano with gentle strings]
Part 2（後半）: [盛り上がり — 例: uplifting orchestral with piano, emotional crescendo]
```

動画の内容・ナレーションの雰囲気に合わせる。ナレーションが落ち着いたトーンなのにBGMがアップビートだと不自然。

#### 6-3. BGMを生成する

ユーザーの確認後、以下を実行:

**30秒以下の場合:**
```bash
python3 /Users/keeee/Desktop/Dev/OssMovieAIz/scripts/generate_music.py \
  --caption "[キャプション]" \
  --duration [動画尺] \
  --output /Users/keeee/Desktop/Dev/OssMovieAIz/public/bgm.mp3
```

**30秒超の場合（2パート別キャプション）:**
```bash
python3 /Users/keeee/Desktop/Dev/OssMovieAIz/scripts/generate_music.py \
  --caption "[Part 1キャプション]" \
  --caption2 "[Part 2キャプション]" \
  --duration [動画尺] \
  --output /Users/keeee/Desktop/Dev/OssMovieAIz/public/bgm.mp3
```

**30秒超で同じ雰囲気を維持する場合:**
```bash
python3 /Users/keeee/Desktop/Dev/OssMovieAIz/scripts/generate_music.py \
  --caption "[キャプション]" \
  --duration [動画尺] \
  --output /Users/keeee/Desktop/Dev/OssMovieAIz/public/bgm.mp3
```

#### 6-4. 結果を確認する

生成後、以下を報告:
```
BGMを生成しました: public/bgm.mp3
尺: [X]秒 / 動画尺: [Y]秒
生成モード: [1発生成 / 2パート分割+クロスフェード]

Remotion Studioでナレーションとのバランスを確認してください。
ボリュームは AdVideo.tsx の <Audio volume={...}> で調整できます。
```

**⚠️ レンダリングはユーザーの指示があるまで実行しない。** Remotion Studioで確認してもらう。
