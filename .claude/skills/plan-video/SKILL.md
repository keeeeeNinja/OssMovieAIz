## ショート動画構成設計スキル

**bs分析のカット数・尺配分をベースに**、テーマに合わせて微調整する。
ゼロから構成を作るのではなく、バズ動画の構造を活かしつつ自分の動画に最適化する。

---

### Step 1: bs分析結果とテーマを確認する

#### 1-1. bs分析結果を確認する

制作フローのStep 2で実行済みのbs分析結果から以下を取得する：
- **カット数**（シーン数）
- **各カットの尺**
- **各カットの役割**（フック/本題/CTA等）
- **テンポ・トランジション**

bs分析結果がまだない場合は「先にbs分析（Step 2）を実行してください」と伝えて終了する。

#### 1-2. テーマと目的を確認する

ユーザーから動画のテーマを受け取る（制作フローStep 4で確認済みのはず）。

まだ教えてもらっていない場合は聞く：
「この動画のテーマ・目的を教えてください（例：まつ毛美容液の広告、飲食店のショート動画など）」

---

### Step 2: 素材画像があれば読み込む

以下のコマンドで画像ファイルを列挙する：

```bash
find /Users/keeee/Desktop/Dev/OssMovieAIz/作業中動画 -maxdepth 1 \( -name "*.jpg" -o -name "*.jpeg" -o -name "*.png" \) | sort
```

画像がある場合はReadツールで読み込み、各画像の内容を把握する。
画像がない場合（まだStep 6の静止画生成前）でもbs分析結果だけで構成設計を進められる。

---

### Step 3: 構成を設計する

**bs分析のカット数・尺配分をベースに**、テーマに合わせて微調整する。

**設計の軸：**

| 要素 | 考え方 |
|------|--------|
| カット数 | **bs分析のカット数を基本とする**。増減する場合は理由を添える |
| 合計尺 | **bs分析の合計尺を基本とする**。変更する場合はユーザーに確認 |
| 秒数配分 | bs分析の尺配分をベースに、テーマに合わせて微調整 |
| フック | 冒頭2〜3秒で視聴者を止める。インパクト優先 |
| 本題 | 商品・サービスの価値を映像で伝える |
| CTA | 最後2〜3秒で行動を促す。シンプルに |

**各シーンで決めること：**

1. **役割** — フック / 本題 / CTA
2. **推奨秒数** — 演出理由とセットで
3. **テロップ** — あり（文言の方向性）/ なし（理由）
4. **カメラワーク** — 動きの種類と、なぜその動きが効果的かの理由
5. **推奨エンジン** — 以下の特性で選ぶ：

| エンジン | 向いている映像 |
|---------|--------------|
| Wan 2.1 | 静物・料理・風景。参照画像に忠実に動かしたい |
| Kling | 人物の動作・表情。リアルな動きが必要 |
| Runway | シネマティックな光・大気感・質感重視 |
| PixVerse | 複数素材の合成・エフェクト重視 |

---

### Step 4: 構成案を提案する

以下のフォーマットで提案する：

```
## 動画構成案（合計XX秒・Xカット）

### Scene 1（X秒）— フック
- 画像: [ファイル名]
- テロップ: あり「〇〇〇」 / なし
- カメラワーク: [例: ゆっくりズームイン] — 理由: [例: 商品に視線を誘導し期待感を高めるため]
- 推奨エンジン: [Wan/Kling/Runway/PixVerse] — 理由: [例: 静物のため参照画像に忠実なWan]
- 秒数の理由: [例: フックは短く2秒でテンポよく切る]

### Scene 2（X秒）— 本題
...

### Scene N（X秒）— CTA
...

---
合計: XX秒 / Xカット
```

提案後、ユーザーの承認を待つ。修正があれば反映して再提案する。

---

### Step 5: プロンプト.mdに保存する

承認後、以下のパスに構成を保存する：

```
/Users/keeee/Desktop/Dev/OssMovieAIz/作業中動画/プロンプト.md
```

保存内容は構成案（Step 4のフォーマット）をそのまま書き出す。

保存後：
```
構成を保存しました。
クリップ生成に進む場合は /wan-video /kling-video /runway-video を使ってください。
```

---

### 注意点

- 秒数は「3秒×5カット＝15秒」のような均等割りをしない
- カメラワークの理由は「演出上なぜその動きが必要か」を具体的に書く
- テロップなしを選ぶ場合も「映像だけで伝わるから」など理由を添える
- 画像が1枚しかない場合でも、それを複数のアングルで使う構成を提案できる
