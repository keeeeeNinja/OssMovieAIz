## ショート動画構成設計スキル

作業中動画フォルダの素材画像を見て、動画の目的に最適な構成を設計する。
秒数を均等割りせず、各シーンの演出価値に応じた尺を割り当てることがこのスキルの核心。

---

### Step 1: 目的を確認する

ユーザーから動画の目的を受け取る。

まだ教えてもらっていない場合は聞く：
「この動画の目的を教えてください（例：化粧品の認知広告、飲食店のショート動画、商品紹介など）」

目的が決まったら、以下も確認する：
- **合計尺の希望**（なければ15秒前後をデフォルトとする）
- **ターゲット**（なければ動画の目的から推測する）

---

### Step 2: 画像を読み込む

以下のコマンドで画像ファイルを列挙する：

```bash
find /Users/keeee/Desktop/Dev/OssMovieAIz/作業中動画 -maxdepth 1 \( -name "*.jpg" -o -name "*.jpeg" -o -name "*.png" \) | sort
```

ファイルが0件の場合は以下の順で探す：
1. `Archive/` 以下のサブフォルダ
2. `LoRA/` 以下のサブフォルダ

それでも見つからない場合は「作業中動画フォルダに画像が見つかりません。画像を入れてください」と伝えて終了する。

見つかったファイルをすべてReadツールで読み込み、各画像について把握する：
- 被写体・商品・人物
- 雰囲気・ライティング・色調
- 動きが想像できるか（静的 vs 動的）
- フック・本題・CTAのどれに向いているか

---

### Step 3: 構成を設計する

画像の内容と動画の目的を組み合わせて、演出上ベストな構成を考える。

**設計の軸：**

| 要素 | 考え方 |
|------|--------|
| 合計尺 | 15秒前後（指定があればそれに従う） |
| 秒数配分 | 均等割り禁止。演出的な重みで決める |
| フック | 冒頭2〜3秒で視聴者を止める。インパクト優先 |
| 本題 | 商品・サービスの価値を映像で伝える |
| CTA | 最後2〜3秒で行動を促す。シンプルに |

**各シーンで決めること：**

1. **役割** — フック / 本題 / CTA
2. **推奨秒数** — 演出理由とセットで
3. **テロップ** — あり（文言の方向性）/ なし（理由）
4. **カメラワーク** — 動きの種類と、なぜその動きが効果的かの理由
5. **推奨エンジン** — 以下の特性で選ぶ：

| エンジン | 向いている映像 |
|---------|--------------|
| Wan 2.1 | 静物・料理・風景。参照画像に忠実に動かしたい |
| Kling | 人物の動作・表情。リアルな動きが必要 |
| Runway | シネマティックな光・大気感・質感重視 |
| PixVerse | 複数素材の合成・エフェクト重視 |

---

### Step 4: 構成案を提案する

以下のフォーマットで提案する：

```
## 動画構成案（合計XX秒・Xカット）

### Scene 1（X秒）— フック
- 画像: [ファイル名]
- テロップ: あり「〇〇〇」 / なし
- カメラワーク: [例: ゆっくりズームイン] — 理由: [例: 商品に視線を誘導し期待感を高めるため]
- 推奨エンジン: [Wan/Kling/Runway/PixVerse] — 理由: [例: 静物のため参照画像に忠実なWan]
- 秒数の理由: [例: フックは短く2秒でテンポよく切る]

### Scene 2（X秒）— 本題
...

### Scene N（X秒）— CTA
...

---
合計: XX秒 / Xカット
```

提案後、ユーザーの承認を待つ。修正があれば反映して再提案する。

---

### Step 5: プロンプト.mdに保存する

承認後、以下のパスに構成を保存する：

```
/Users/keeee/Desktop/Dev/OssMovieAIz/作業中動画/プロンプト.md
```

保存内容は構成案（Step 4のフォーマット）をそのまま書き出す。

保存後：
```
構成を保存しました。
クリップ生成に進む場合は /wan-video /kling-video /runway-video を使ってください。
```

---

### 注意点

- 秒数は「3秒×5カット＝15秒」のような均等割りをしない
- カメラワークの理由は「演出上なぜその動きが必要か」を具体的に書く
- テロップなしを選ぶ場合も「映像だけで伝わるから」など理由を添える
- 画像が1枚しかない場合でも、それを複数のアングルで使う構成を提案できる
